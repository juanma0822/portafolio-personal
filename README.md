# Portafolio - Juan Manuel Valencia Triana

Proyecto de portafolio personal creado con Vite + React.

Comandos:

```bash
npm install
npm run dev
```

Notas rápidas:
- El CV imprimible está disponible en `cv.html`.
- Para construir producción: `npm run build` y `npm run preview` para previsualizar.
 - La app usa `framer-motion` para micro-interacciones.
 - La foto de perfil se encuentra en `public/profile.jpg`.
